# PlayerAgent · 像素人格实验室

电脑浏览器运行的规则 Agent 实验原型。观看四种模拟行为画像自主选路，调整参数并比较结果。像素素材由程序绘制，无需模型账号。

## 启动

安装 Node.js 22，在项目目录执行 `npm ci`，然后执行 `npm run dev`，打开终端显示的网址。

`npm run build` 生成 dist 静态网页。仓库 downloads/PlayerAgent-v0.4.0-web.zip 是已构建网页包，解压后部署到 HTTP 静态服务，不直接双击 HTML。

## 本版内容

- 八个关卡，默认第八关“矿道双线”：上层钥匙 → 门 → 宝箱，下层窄桥捷径，两路在宽地面汇合。
- 四种画像：谨慎、冒险、收集、探索；七项参数：安全、奖励、速度、探索、耐心、目标坚持、路线记忆。
- 所有画像跳高约 96 像素，完整跳跃水平距离固定 140 像素，支持地面左右平移。
- 移动平台、周期陷阱、巡逻怪、跳跃怪、不可踩踏的装甲怪；敌人主要分布在宽地面。
- 暂停、单步、加速、决策说明、任务进度、本局记忆、四画像批测和 JSON 导出。

## 观察支路

选择第八关，分别选择收集型和冒险型并重试。默认种子 42 的结果：收集型走上层宝藏支路，7.02 秒、57 金币；冒险型走下层窄桥，5.62 秒、2 金币，两者都通关。这是指定配置下的结果，并非所有地图都有相同收益。

“运行四画像对比”运行当前关卡的默认四画像 × 五种子（42—46），不使用自定义滑块。修改滑块后重试才能应用；运行中的参数不变。页面保存最近 100 条结果，JSON 包含种子、版本、参数、路线、耗时、伤害和任务事件。

## Agent 规则与修改入口

1. src/modules/world/levels.ts：地图、支路、金币、机关、敌人和任务节点。
2. src/gameplay/Motion.ts：统一运动能力和落点可达性判断。
3. src/agent/planning/RulePlanner.ts：用画像权重评价奖励、距离、危险和新颖性。
4. src/agent/personality/profiles.ts：默认画像参数。
5. src/agent/memory/SessionMemory.ts：本局访问、受伤和暂时阻塞记忆。
6. src/gameplay/TaskChain.ts：钥匙、开门、宝箱状态机。
7. src/gameplay/Simulation.ts：观察、目标评分、等待、平移、跳跃、碰撞与结算。
8. src/gameplay/DynamicWorld.ts 与 src/modules/enemies/EnemyBehavior.ts：机关周期和敌人运动。
9. src/scenes/GameScene.ts：像素画面；src/main.ts：实验界面交互。

## 验证与边界

`npm test` 运行 15 项测试，涵盖原七关 × 四画像 × 五种子路线差异、矿道五种子收集/冒险取舍、任务顺序、记忆隔离、固定运动和复现。`npm run build` 执行类型检查和打包。详细调整说明见 docs/architecture.md。

当前没有 LLM、视觉识别、强化学习或真人情绪推断。画像是人工偏好，不能作为人格心理学结论。金币按落到平台领取，新颖性由地图配置；任务目标是已知路标。种子影响敌人和机关相位，没有随机因素时结果可能相同。独立菜单、音效和完整资源加载流程仍待扩展。
